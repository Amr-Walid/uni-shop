# Uni-Shop Mobile — تطبيق يونى شوب

تطبيق Flutter للأندرويد والآيفون، مبني على الـ Web API الموجود في
`FTD.Api` (`/api/v1`).

---

## 1. التشغيل السريع

```bash
# 1) شغّل الـ API أولاً
cd FTD.Api
ASPNETCORE_ENVIRONMENT=Development ASPNETCORE_URLS=http://0.0.0.0:5100 dotnet run

# 2) شغّل التطبيق
cd mobile
flutter pub get
flutter run
```

### عنوان الـ API

القيمة الافتراضية في `lib/core/config/env.dart` هي `http://10.0.2.2:5100`
وهو العنوان الذي يرى به **محاكي الأندرويد** الـ `localhost` الخاص بجهازك.
للحالات الأخرى:

| الحالة | العنوان |
|---|---|
| محاكي أندرويد | `http://10.0.2.2:5100` (الافتراضي) |
| محاكي iOS | `http://localhost:5100` |
| جهاز حقيقي | `http://<IP-جهازك>:5100` |
| الإنتاج | دومين HTTPS |

بدون إعادة بناء الكود:

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.5:5100
```

> **الأندرويد وHTTP:** الاتصال غير المشفّر مسموح في `debug` فقط.
> نسخة `release` تتطلب HTTPS — وهذا مقصود، لأن إرسال توكن الدخول
> على HTTP يعرّضه للاعتراض.

## 4. قرارات تقنية مهمة

هذه ليست تفاصيل شكلية — كل بند منها يمنع خطأً حقيقياً:

### المال يُحسب بـ `Decimal` لا `double`
قاعدة البيانات تخزّن `decimal(18,2)`. النوع `double` لا يمثّل `0.1` تمثيلاً
دقيقاً، فتظهر فروق قروش في الإجماليات. لذلك كل سعر في التطبيق `Decimal`.

### تحديث التوكن محمي بـ mutex
`AuthInterceptor` يمتد من `QueuedInterceptor` ويحمل قفلاً: لو رجعت عشرة
طلبات بـ 401 في نفس اللحظة، يُنفَّذ `/auth/refresh` **مرة واحدة** وتنتظره
البقية. بدون هذا القفل، تسع محاولات تحديث ستُستهلك بتوكنات قديمة —
والسيرفر يعتبر إعادة استخدام التوكن سرقةً ويُلغي الجلسة بالكامل.

### الشراء يحمل `Idempotency-Key` واحداً لكل محاولة
لو انقطعت الشبكة بعد وصول الطلب للسيرفر وقبل وصول الرد، إعادة المحاولة
بنفس المفتاح تُرجع نفس النتيجة بدل إنشاء أوردر ثانٍ وخصم المخزون مرتين.
المفتاح لا يتغيّر إلا بعد نجاح مؤكد.

### السلة محلية أولاً
الإضافة للسلة لا تنتظر الشبكة إطلاقاً — تُحدَّث الحالة وتُحفَظ فوراً.
السيرفر يُستشار مرة واحدة فقط: `POST /cart/validate` قبل الشراء، وهي
النقطة الوحيدة التي تهم فيها الدقة (نفاد مخزون أو تغيّر سعر).

### الترتيب والصفحات
`hasNext` من السيرفر هو ما يقود التحميل اللانهائي، وليس
`items.length < pageSize` — تلك المقارنة تفشل عندما تكون الصفحة الأخيرة
ممتلئة تماماً. كذلك `appendTo` يحذف المتكرر بالمعرّف، لأن منتجاً يُضاف بين
جلبتين قد يظهر في الصفحتين.

### النصوص من السيرفر لا تُترجم في التطبيق
الـ API يقرأ `Accept-Language` ويُرجع حقلاً واحداً مترجماً لكل قيمة. لذلك
أسماء المنتجات والأقسام وحالات الأوردر لا توجد في ملف الترجمة — وجودها
هناك يعني خطر إظهار ترجمة قديمة.

الاستثناءان الوحيدان: `AttributeFilterGroupDto` و`ContentPageDto` يرسلان
العمودين معاً لأنهما أقدم من الـ endpoints الخاصة بالموبايل ومشتركان مع
لوحة الإدارة.

### مقاس فك ضغط الصور محدود
صورة 2000px يرفعها الأدمن تُفك في خانة 180px بحجم ~16 ميجابايت لكل خانة.
`memCacheWidth` يقصّها على مقاس العرض، وإلا انهار التطبيق على أجهزة
أندرويد المتوسطة بعد عدة شاشات تمرير.

### الأدوار للعرض فقط
`isAdmin` يُستخدم لإظهار عنصر واجهة، ولا يحمي أي عملية. الحماية الحقيقية
في `[Authorize(Roles = "Admin")]` على الـ API، لأن أي قرار يتخذه العميل
قابل للتلاعب.

## 5. الاتجاه من اليمين لليسار (RTL)

العربية هي اللغة الأساسية، والتطبيق مبني RTL-first:

- الخط **Cairo** عبر `google_fonts` — الخط الافتراضي Roboto لا يدعم العربية
  ويسقط على خط النظام، فيختلف الشكل بين أجهزة أندرويد وiOS.
- `height: 1.6` للنصوص: العربية بها نزول عميق وتشكيل يتراكم، ويتصادم عند
  الارتفاع الافتراضي.
- `PositionedDirectional` و`AlignmentDirectional` في كل مكان — الشارات
  وزر المفضّلة تنقلب تلقائياً.
- الأرقام غربية (`450` لا `٤٥٠`) لأن هذا هو العُرف في التجارة المصرية.
- العملة بعد الرقم في العربية وقبله في الإنجليزية.
- اتجاه وميض `Shimmer` يتبع اتجاه القراءة.
- مقياس خط النظام محدود بـ `1.3x`: كثير من الأجهزة المصرية مضبوطة على خط
  كبير، وفوق ذلك يتصادم اسم المنتج مع السعر.

## 7. ما تبقّى قبل النشر

- [ ] `MediaBaseUrl` في `FTD.Api/appsettings.json` يجب أن يكون دومين
      HTTPS حقيقياً، وإلا وصلت روابط صور غير قابلة للتحميل.
- [ ] `JwtSettings:Secret` — مفتاح إنتاج 32 بايت على الأقل من متغيرات
      البيئة أو Key Vault (السيرفر يرفض الإقلاع بدونه).
- [ ] إشعارات Firebase: `google-services.json` و`GoogleService-Info.plist`
      ثم استدعاء `/devices/register`.
- [ ] أيقونة التطبيق وشاشة البداية.
- [ ] `/api/v1/app/config` — ضبط `MinSupportedVersion` وروابط المتاجر
      لتشغيل التحديث الإجباري.
- [ ] توقيع النسخ: keystore للأندرويد، وشهادة التوزيع لـ iOS.

## قاعدة البيانات — اختيار المزوّد

المشروع بيقرأ `Database:Provider` وبيستخدم **`SqlServer` كافتراضي**. يعني أي حد بيعمل
`git clone` أو `git pull` بيشتغل على SQL Server زي الأول بالظبط، من غير أي إعداد.

| المزوّد | بيتحفظ؟ | الاستخدام |
|---|---|---|
| `SqlServer` | ✅ | **الافتراضي** — الإنتاج والتطوير العادي |
| `Sqlite` | ✅ ملف واحد | جهاز مافيهوش SQL Server (Development فقط) |
| `InMemory` | ❌ | عرض سريع أو CI (Development فقط) |

`Sqlite` و `InMemory` **بيرفضوا الإقلاع خارج Development**. السبب إن `Sqlite` بيكتب في
ملف محلي مافيش pipeline بيديره، و`InMemory` مالوش حفظ ولا قيود علائقية أصلًا — فالقبول
الصامت لأي منهم في الإنتاج كان هيبقى **خطأ فقدان بيانات**، مش تسهيل.

### تشغيل محلي على Sqlite (من غير ما تأثر على حد تاني)

اعمل ملف `appsettings.Local.json` (موجود في `.gitignore`) جوه `FTD.Web` أو `FTD.Api`:

```json
{ "Database": { "Provider": "Sqlite" } }
```

أو من البيئة: `Database__Provider=Sqlite`

الملف بيتحمّل **بعد** ملفات `appsettings` المتتبَّعة فبيتغلّب عليها، بس **قبل** متغيرات
البيئة — فملف محلي منسي مش هيقدر يتغلّب على إعدادات النشر.

### ملاحظات مهمة على Sqlite

- **الـ migrations مش بتشتغل عليه.** الـ migrations المكتوبة هنا خاصة بـ SQL Server:
  فيها أعمدة `nvarchar(max)` (خطأ صياغي في Sqlite) و`GETUTCDATE()` (مش موجودة فيه).
  فـ Sqlite بيبني السكيما من الموديل بـ `EnsureCreated` بدل الـ migrations.
- **أعمدة الفلوس بتتحول لـ `REAL`.** Sqlite مالوش نوع `decimal`، وEF بيخزّنه `TEXT`،
  والقاعدة بتقارنه كنص. مع أسعار 899 و 8999 و 10000 الترتيب التصاعدي كان بيرجع
  **10000, 899, 8999** لأن `"1" < "8"` — وده كان بيكسر الترتيب بالسعر و`SUM` في
  الداشبورد. التحويل لـ `REAL` بيرجّع المقارنة رقمية. `REAL` نوع عشري ثنائي فمش
  بيمثّل كل قيمة بمنزلتين بدقة مطلقة، وعشان كده التحويل ده **بيتطبق على Sqlite بس**؛
  SQL Server بيفضل `decimal(18,2)` بدقته الكاملة.
